# 圖片排版產生器

[![test](https://github.com/cormort/ppt-layout-generator/actions/workflows/test.yml/badge.svg)](https://github.com/cormort/ppt-layout-generator/actions/workflows/test.yml)

用版型把內容排成簡報：照片美編、整份簡報（含逐字稿）產生、HTML 播放，都在瀏覽器裡完成；需要時再交給 PowerPoint 繼續加工。

## 介面

- **上方列**：「檔案」（開啟 PPTX、大綱 Markdown、開啟／另存專案、新簡報、介面外觀）、復原／重做；右邊「匯出」與 **▶ 播放**
- **功能區鍵盤**：`Alt+1`…`Alt+6` 直接切換功能區分頁；分頁列有焦點時 `←`／`→`（`Home`／`End`）移動；視窗窄於約 1200px 會收緊字級，真的放不下時右側出現「»」與渐層提示（可橫向捲動）
- **功能區**（桌面，像簡報軟體的 Ribbon）：**常用**（新增／複製／刪除／移動投影片、版面配置、編輯文字、照片）／**插入**（照片、圖表、地圖、封面、章節頁、目錄、匯入 PPTX、Markdown 大綱、Logo、頁尾）／**設計**（投影片大小、8 套套裝、配色、字型、項目符號、字級）／**投影片放映**（從頭開始、從目前投影片、HTML 播放檔、講義）／**匯出**（PowerPoint、HTML、PDF 講義、下載這一頁、複製圖片、大綱 .md、專案）／**檢視**（投影片窗格、備忘稿、格式窗格開關、介面外觀）
- **狀態列**（桌面）：目前第幾張、版面尺寸；右邊切換備忘稿、格式窗格與播放
- **左欄**：頁面清單（拖曳排序；目前頁可上移、下移、複製、刪除）
- **中間**：投影片畫布＋正下方的**逐字稿**（顯示字數與唸稿時間）；上方顯示「文字都放得下」或放不下的提醒
- **右欄**四個分頁：**內容**（目前版型、標題、副標、項目清單編輯器、內文／大數字）／**版型**（「建議」只列出這一頁放得下的版型）／**照片**（照片庫、這一頁的照片順序與裁切）／**樣式**（整份共用的配色、字體、項目符號、Logo、頁尾）
- **手機**：畫布固定在上方，底部分頁「頁面／內容／版型／照片／樣式」，播放與匯出在右上角；逐字稿在「內容」分頁

線上使用：https://cormort.github.io/ppt-layout-generator/

## 範本

71 組版型，可用分類快速篩選（建議、封面／標題 14、文字頁 6、圖表 4、地圖 1、圖卡 8、對比 2、照片牆 3、雜誌風 4、章節頁 5、形狀拼貼 6、目錄 5、圖文分格 3、商務 7、中國風 3）：

- 文字頁（不用圖片，文字多時自動縮字、分欄）：條列重點、重點方格、表格、標題＋段落、引言金句、數據並列（2–4 個大數字＋標籤＋一行說明）
- **圖表**（任何尺寸都能用）：直條圖、橫條圖、折線圖、環圈圖。項目第一欄是類別、其餘欄是數值（最多 4 組），第一列可放系列名稱；**直接貼上 Excel 表格**就會轉成項目並自動套用圖表（年度、月份等趨勢資料用折線，類別名稱長或很多列用橫條）。內文顯示為下方的資料來源
- **地圖**（16:9）：台灣縣市統計標註 —— 地圖在中間，有資料的縣市上色，左右長出標註框並用細線指回地圖（最多 12 個縣市；澎湖、金門、連江畫成下方小圖）。項目第一欄寫縣市名（「臺」寫成「台」也認得、市縣後綴可省略），其餘每一欄各是一行說明，例如 `臺中市|農糧：蘋果、甜柿|畜牧：豬`；標題放右上方、副標當大字（例如「累計 4 億 4,623 萬元」），內文是下方的資料來源。輪廓取自內政部縣市界線，換新版界線要跑 `node scripts/gen-tw-map.mjs`（產生 `src/js/05-tw-map-data.js`，主檔只多約 40 KB）。範例：`examples/地圖-縣市農業損失.md`
- **圖卡**（1:1、4:5、3:4、9:16）：照片公告、活動公告、重點清單、數據亮點、金句、人物引言（一張人像＋金句）、去背主體（主體放色塊上；沒去背的照片自動裁成圓形）、花瓣扇（5–8 張照片排成一朵花，一片花瓣一張；副標是花上方那行小字，標題在花的一側；16:9 也適用 —— 花朵在左、文字在右，直式改成花朵在上、文字在下）
- **對比**（任何尺寸）：前後色帶（2 張照片並排，直式自動改上下堆疊，項目填「之前|說明」「之後|說明」）、VS 圓標（兩張圓角照片＋中間 VS）
- **照片牆**（任何尺寸）：2–6 張照片自動拼成一牆，標題疊在底部漸層上；**夜空羽化**（16:9）＝深色星空底＋截圖牆往四周淡出＋中央主圖與倒影（第一張當主圖、其餘放進 7×4 的牆），標題是上方字標、內文是下方字幕，四周有羽化所以不會像貼紙；**曲面拼貼**（16:9）＝海報式拼貼：左側圓弧面板放 1 張主圖與奶油色標題（左上壓一層暗霧，字才讀得出來），右側 35 格（7×5）透視網格沿底部鏡射成倒影、遠端加霧、牆腳加接觸陰影；格子共用同一份圖片（`<use>`），所以 35 格只內嵌一次照片，超過 12 張只取前 12 張輪流
- **雜誌風**（16:9）：封面、專題、兩欄文章（首字放大）、目錄；襯線字、暖紙底、不對稱留白
- **中國風**（任何尺寸）：直排、撕紙分界（照片＋宣紙＋直排標題＋印章）、宣紙金句（直排金句＋落款）
- 結尾頁：感謝頁（大標＋一句話，任何尺寸）

## 套裝（整份簡報一起換）

單一版型好看，不代表整份簡報好看 —— 一份簡報要「封面→章節→內容→數據→照片→結語」都在同一個語言裡。
「設計」功能區或「樣式」分頁的**套裝**，一鍵把整份簡報換成同一套設計：配色、標題與內文字體、結構頁的版型
（封面／章節／目錄／文字／引言／表格／照片／照片牆／結尾）。樣式分頁的套裝按鈕會用**第 1 頁的內容**畫出各套的封面，先看再套；
目前樣式符合的那套會標起來。**只換版型與樣式，標題、項目、照片一個字都不動**，按復原可以退回去。

圖表、地圖、數據並列、重點方格、圖卡、商務（時間軸、流程、數據亮點…）、對比、直排這些頁**保留原版型**，只換配色與字體——
它們的版型就是內容的形狀（折線圖不該變直條、地圖不該變長條）。套裝之間可以來回切換，不會越換越偏。內建 8 套：

| 套裝 | 語言 | 封面 → 章節 → 目錄 → 照片 |
|---|---|---|
| 年度報告 | 藏青金、正式保守 | 封面左右分割 → CHAPTER 豎條照片 → 大字編號 → 弧頂分格 |
| 課程講義 | 墨綠米、字大、投影清楚 | 巨字排版 → 大數字鏤空 → 大字編號 → 弧頂分格 |
| 品牌提案 | 酒紅灰、襯線字暖紙底 | 雜誌封面 → 數字＋淡出照片 → 雜誌目錄 → 圓形拼貼 |
| 專案回顧 | 商務藍、動態感 | 中央字標 → 滿版照片＋大數字 → 大字編號 → 波浪分格 |
| 科技發表 | 科技紫、產品發表 | 三角切割 → 滿版照片＋大數字 → 弧面屏 → 六邊形蜂巢 |
| 東方雅韻 | 硃砂金、標楷＋明體 | 撕紙分界 → 數字＋淡出照片 → 圓環 → 扇形畫廊（金句用宣紙金句） |
| 活動紀錄 | 深灰橘、成果與紀錄 | 層疊色帶 → 大數字鏤空 → 半環扇形 → 弧頂分格 |
| 新創提案 | 青綠橘、年輕俐落 | 螢光標記 → CHAPTER 豎條照片 → 霧面豎板 → 波浪分格 |

「樣式」分頁的套裝下方有**＋ 把目前樣式存成套裝**：把現在的配色、字型與「每一種角色用哪個版型」存成一套自訂套裝
（存在這台電腦的 localStorage，換瀏覽器不會跟著走；卡片右上角可以刪除）。功能區「設計」分頁也會列出這些自訂套裝。

命令列同樣支援：`node cli/pptgen.mjs build 大綱.md --suite 年度報告`（會蓋掉大綱裡指定的版型；想保留就別加）。
`node cli/pptgen.mjs templates` 會列出套裝清單。

## 逐字稿、套裝檔、多選頁面、圖庫整理

- **逐字稿匯出**（匯出 → 逐字稿 .md／.txt）：每頁帶頁碼、版型、字數與預估秒數（250 字／分鐘），可以直接印或寄給講者。
- **自訂套裝可以帶走**（樣式 → 匯出自訂套裝／匯入套裝）：`.json` 檔含配色、字型與角色對應；匯入時會驗證格式與字體索引，重複的 id 不會蓋掉。**專案檔（`.pptgen.json`，v3）也會把自訂套裝一起存**，換電腦載入專案就一併帶回來。
- **多選頁面**：左側頁面清單 `Ctrl`／`⌘` 點逐頁加選、`Shift` 點選一段；選兩頁以上會出現批次列，可**套用這一頁的版型**或**刪除**；在「版型」分頁點任何一張卡片也會直接套到選取的每一頁。**切換版面尺寸時選取會保留**，批次套用會自動換成新尺寸支援的相近版型。
- **圖庫整理**（照片分頁）：沒被任何一頁用到的照片會標「未用」並壓暗，可勾「只看未使用」、按「移除沒用到的」；雙擊照片改名；統計列顯示張數與總容量。
- **HTML 播放檔會壓圖**：匯出時把圖重新編碼成 WebP（長邊 1600、品質 0.82），檔案常見小一半；瀏覽器不支援 WebP 時原樣保留。命令列 `--html` 也走同一條路。
- **簡報者檢視匯出**（放映 → 簡報者檢視）：產生的 HTML 一開啟、點一下畫面就會**多開一個講者視窗**（逐字稿＋計時＋**下一頁預覽（含頁名，限高 34vh 不擠壓逐字稿）**）；單螢幕可按 `P` 關掉。

## 版型庫：最近使用與收藏

「版型」分頁的分類多了 **最近**（用過的最多 8 個，愈新愈前面）與 **收藏**（每張卡片右上角的 ☆）。
兩個清單都存在這台電腦的 localStorage；按星號只會加／取消收藏，不會動到目前這一頁的版型。

## 命令列也能一次做完：`doctor`

```sh
node cli/pptgen.mjs doctor 大綱.md            # 容量檢查＋健檢，列出可自動修的項目
node cli/pptgen.mjs doctor 大綱.md --fix      # 直接修（重複標題／缺標題／放不下的版型）並存成 大綱_修好.md
node cli/pptgen.mjs doctor 大綱.md --fix -o 修好.md --json
```

- 有問題時 **exit 1**（可以直接放進 CI 或 git hook），沒有問題 exit 0；`--json` 給程式讀。
- `--fix` 只修「能安全自動修」的三種：重複標題加「（續）」、沒有標題補版型名、放不下換同分類放得下的版型；
  **原檔不會被改**，修好的結果另存新檔。
- 缺照片只會提示（要照片才能修），會告訴你有幾頁、哪幾頁。
- **輸出前自動先跑**：`build 大綱.md --doctor` 會先印健檢結果再產生檔案（exit 0，不會因為提醒而失敗）；
  加 `--fix` 會先在記憶體裡修好再輸出，**大綱檔不會被改**（想保存修好的大綱就用 `doctor --fix`）。

## 匯出前的提醒與狀態列

- **匯出前先講清楚**：還有頁面用示意圖（照片版型但沒選照片）時，第一次按匯出只會提醒「還有 N 頁沒有照片」，
  四秒內再按同一個按鈕就直接匯出（PPTX、HTML、講義共用同一個判斷，不用瀏覽器彈窗）。
- **狀態列的問題數**：右下角會顯示「N 個問題」，點一下直接開簡報健檢；沒有問題時就收起來。
- **PPTX 進度**：整份輸出時每 10% 回報一次，不會洗版也不會像卡住。
- **套裝的目錄會看章數**：8 章以內用大字編號，超過 8 章自動改用清單式目錄（大字編號會被截掉）。
- **缺照片可以直接換掉封面**：健檢的「缺照片」在全部都是封面時提供一鍵修（換成純文字封面）；章節頁沒有替代方案，只提示。

## 大綱寫法的一個重點

一行裡只要有 `|`（`類別|數值`、`欄位|欄位`）就會被當成**項目**，不用再加 `- ` 或 `| … |`。
以前這種寫法會整串跑進內文，圖表因此沒有資料、健檢還會誤報「內文放不下」。

## 簡報健檢

功能區「檢視」→**簡報健檢**（或右下角狀態列旁）會把整份簡報掃一遍，列出：

- **文字放不下**：用這一頁自己的內容渲染一次，跟「建議版型」用同一套判斷
- **缺照片**：需要照片的版型目前用示意圖
- **沒有標題／標題重複**：同名兩頁很容易被誤認為重複頁
- 統計「幾頁沒有逐字稿」（不逐頁列，免得變成三十列的清單）

- 點清單裡任何一列就跳到那一頁。

有「**修**」的項目可以一鍵處理（或按「一鍵修（N）」全部修完，修完還能按復原）：重複標題加上「（續）」、
沒有標題補上版型名、文字放不下自動換成**這一頁放得下的**版型（先找同分類、最多試 40 個）；缺照片要有照片才能修，只提示。

## 版面尺寸

「樣式」分頁最上方可切換整份的尺寸：**16:9 簡報**、**1:1**（FB／IG 貼文）、**4:5**（IG 直式貼文）、**3:4**（小紅書／FB 直式）、**9:16**（限時動態、LINE 直式）。1:1／4:5／3:4／9:16 可用 30 組版型：文字頁 6（條列、方格、表格、段落、引言、數據並列；直式時最多兩欄）、圖表 4、圖卡 8、對比 2、照片牆 1、目錄大字編號 1、中國風 2、雙色調封面 1、文字封面 4、感謝頁 1；照片拼貼、封面、章節頁、商務、雜誌風等只有 16:9。切換時，這個尺寸不支援的版型會換成相近的版型（例如章節頁→數據亮點卡、照片版型→照片公告卡、雜誌目錄→條列；可按復原）；PNG、PPTX、HTML 簡報都會用新尺寸輸出。命令列加 `--ratio 3:4`。
- 形狀裁切：菱形拼貼、心形拼貼、六邊形蜂巢、葉形大樹、圓形拼貼、方塊溶解
- 封面／標題：**文字封面**（不用圖片、任何尺寸：巨字排版、框線典雅、螢光標記、浮水印大字；標題自動取最大字級並讓各行等長）、**下緣色帶**（照片在上、下方主色帶放標題，內文放色帶右側；任何尺寸）、**中央字標**（滿版照片＋置中字標：小標→細線→大字→一句話，電影海報感；任何尺寸、自動壓中央暗霧）、三角切割、弧形半版、膠囊豎條、層疊色帶、大字鏤空＋豎條、漸層淡出（副標＝地點／日期、內文＝一行說明）、雙色調（照片用主色增值）、感謝頁
- 章節頁：大數字鏤空、數字＋淡出照片、CHAPTER 豎條照片、滿版照片＋大數字（可依項目清單**連續編號批次輸出**，一次做出 01、02、03… 每章一頁，PPTX 為多頁簡報）、**大數字色塊**（不用照片、任何尺寸：一側主色塊放章節數字、另一側放章名）
- 目錄：半環扇形、霧面豎板、弧面屏、圓環、大字編號（01 02 03… 當視覺主角，最多 8 章、5 章以上自動排 2 列）
- 圖文分格：波浪分格、弧頂分格、扇形畫廊
- 商務：封面左右分割、左圖右文條列、數據亮點、時間軸、斜切時間軸（1 張滿版照片斜切，年份／事件／說明沿斜線往上排，最多 5 個節點；項目填「2022-2024｜Green Shipping｜說明」）、流程步驟、圖文卡片
- 中國風：直排、撕紙分界、宣紙金句

## 多頁簡報與逐字稿

- 左欄的頁面清單：新增、複製、刪除、拖曳或 ↑ ↓ 排序；`PageUp`／`PageDown` 切換頁面
- **章節頁同步**（預設開）：在一個章節頁換成另一個章節版型，或換照片，其他章節頁會一起換成同一個版型、同一張照片；各頁的章節數字與標題不變。章節頁的「內容」分頁可關掉
- 項目用清單編輯（每項一列，「重點」「說明」分欄，表格會自動多出欄位）；要整批貼上時按「文字模式」
- 每頁各自有範本、文字、照片（含順序）與**逐字稿**；配色、字體、字級、Logo、頁尾整份共用
- 「輸出整份 PPTX」把所有頁面輸出成一份簡報，逐字稿寫進每頁的**備忘稿**（單頁下載 PPTX 也會帶逐字稿）
- 專案存檔會存下所有頁面與各頁用到的圖片（舊版專案檔載入後成為單頁）
- 圖庫（原圖、縮圖、裁切）自動存在瀏覽器的 IndexedDB，重新整理後各頁的照片仍在；移除的圖片可以按復原救回（最近 30 張）
- **去背**（照片分頁：選一張照片 → 裁切面板下方「去背」、可調容許度）：把背景變透明、另存一張「（去背）」照片，原圖保留；去背版在版型裡會**完整顯示不裁切**（適合商品、人像、剪影放在色塊上）。圖庫右下角有「透」標記。純前端處理、不用上傳，白底／攝影棚背景效果最好，背景太複雜時演算法抓不準
- **混色與不透明度**（同一面板）：色彩增值、濾色、重疊、變暗、變亮＋不透明度，讓照片和底色融在一起（雙重曝光、照片壓在色塊上）。PNG、PPTX、PDF、HTML 播放器的輸出都會保留同樣的效果
- ⚠ 瀏覽器可能自行清除網站資料（例如 Safari 對 7 天沒開的網站、或磁碟空間不足時），**重要的簡報請另外「專案存檔」成 .pptgen.json**
- 同一個瀏覽器請只開一個分頁編輯：兩個分頁的存檔會互相覆蓋（偵測到時會提醒）
- **項目符號**（樣式分頁）：編號方塊、編號圓圈、圓點、打勾、箭頭、菱形、短豎條、星形，套用到條列重點、標題＋段落、重點清單卡；「依版型預設」維持各版型原本的樣子
- 頁尾「第 1 頁頁碼」填 `P.01`，之後每頁自動遞增（P.02、P.03…）
- PPTX 文字可選「可修改・逐行」（外觀最接近）、「可修改・整段」（改字會自動重排）或「轉成圖片」（外觀完全一致）；底圖可選標準 2 倍或精簡 1 倍

## 播放與 HTML 簡報

- 上方的 **▶ 播放**：從目前這一頁開始，在新分頁播放
- 「匯出 → 講義」：每頁投影片＋逐字稿，直接叫出列印，可存成 PDF 發給學員
- **匯出 HTML**：整份簡報存成單一 `.html`（文字為主的 90 頁約 0.8 MB；照片會內嵌在檔案裡、體積約增加三分之一，照片多的簡報可能到數十 MB，寄送前留意大小），任何電腦用瀏覽器開啟就能播放，不需要安裝 PowerPoint；畫面與預覽完全一致，沒有 PPTX 文字框位置估算的問題
- 快捷鍵：→ ↓ 空白 PgDn 下一頁、← ↑ PgUp 上一頁、數字＋Enter 跳頁、Home／End、**F** 全螢幕、**B** 黑幕；點畫面左側上一頁、其他地方下一頁，手機可左右滑；翻頁筆可直接使用
- **P 簡報者檢視**（另開視窗，可拖到筆電螢幕）：目前頁、下一頁預覽、逐字稿（A−／A＋ 調字級）、經過時間（翻到第 2 頁自動開始，可暫停／歸零）與時鐘；在簡報者視窗翻頁，投影畫面會同步
- 瀏覽器若擋住彈出視窗，請允許該頁面開新視窗

## 匯入既有簡報（PPTX）

在「檔案」選單按「開啟 PPTX」，讀取每張投影片的標題、文字框、表格、照片與備忘稿，自動判讀成頁面並套用版型：

- 最大字的框（或標題版面配置區）當標題，緊接在下面的說明當副標題；章節大數字、引言頁會自動辨識
- 同一欄上下相疊的框合成一張「卡片」＝一個項目（例如「痛點」標籤＋「多檔整理耗時錯位」＋說明），上方或左邊的小標籤會接在前面
- PowerPoint 表格轉成表格頁；占畫面 3% 以上的照片會放進圖庫並接到該頁（Logo、小圖示略過）
- PowerPoint 圖表讀出類別、系列與數值，轉成直條／橫條／折線／環圈圖頁；同一頁文字很多時保留文字頁、圖表另接一頁在後面
- SmartArt、動畫不會轉換
- 匯入後可再「匯出大綱 .md」交給 AI 改寫，再匯回來

## Markdown 大綱匯入／匯出

在「檔案 → 大綱（Markdown）」貼上或開啟 `.md` 大綱，按「取代全部頁面」或「加在後面」就會變成多頁簡報；也可以把目前的頁面匯出成大綱，交給 AI 改寫後再匯入。

```markdown
<!-- 版型: 封面 -->
# 簡報標題
## 副標題
> 這一頁的逐字稿（寫進 PPTX 備忘稿）

---
# 第二頁標題
- 重點一|說明
- 重點二|說明

---
# 驗收指標
| 指標 | 目標 |
|---|---|
| 正確率 | 100% |
```

- 每頁用 `---` 分隔，或直接用下一個 `# 標題` 開新頁
- `#` 標題、`##` 副標題、`數字: 01` 大數字、`-`／`1.` 項目（`|` 後為說明）、`| 表格 |` 每列一行、`>` 逐字稿、其他文字為內文
- `<!-- 版型: … -->` 可寫範本 id、名稱或「條列、方格、表格、段落、引言、封面、章節、大標題、長條、橫條、折線、環圈、雜誌封面、專題、文章、目錄、公告、照片公告、重點卡、數據卡、金句卡、地圖」；沒寫時依內容自動挑選（**數字表格自動變圖表**）

## 命令列（CLI）與 Claude Skill

讓 AI 只寫大綱、排版交給工具：`cli/pptgen.mjs` 在背景（headless）Chrome／Edge 執行同一份 `index.html`，結果與網頁版完全相同。需要 Node 22 以上。

```bash
node cli/pptgen.mjs check 大綱.md                      # 只檢查：版型分配、哪幾頁文字放不下
node cli/pptgen.mjs build 大綱.md -o 簡報.pptx --palette 商務藍
node cli/pptgen.mjs preview 大綱.md --pages 1,3-5      # 指定頁輸出 PNG
node cli/pptgen.mjs from-pptx 舊簡報.pptx -o 大綱.md   # 既有 PPTX → 大綱（含逐字稿）
node cli/pptgen.mjs build 舊簡報.pptx -o 新簡報.pptx    # 直接重新排版既有簡報（照片一起帶過來）
node cli/pptgen.mjs templates                         # 版型清單
node cli/pptgen.mjs install-skill                     # 安裝 Claude Skill 到 ~/.claude/skills
```

其他選項：`--html 簡報.html`（同時輸出可播放的 HTML 簡報）、`--color/--accent/--bg`、`--font/--body-font`、`--scale`、`--text image`（文字轉圖）、`--quality small`（小檔）、`--project 檔.pptgen.json`（另存網頁版專案檔，可載入後換照片微調）、`--json`。用 `--help` 看完整說明。

`skill/SKILL.md` 教 AI 大綱格式、各版型容量與「檢查 → 只修被點名的頁 → 產生」流程；安裝後在 Claude Code 說「把這份講稿做成簡報」即可。

## 輸出

- 格式 **PNG／JPG／SVG／PPTX**（SVG 為向量；PPTX 是真正的 PowerPoint 檔：版面為底圖，所有文字都是可直接修改的文字框）
- 倍率 **1×／2×／3×**（最大 5760×3240）
- 一鍵複製 2× PNG 直接貼上、可用檔名自訂
- **打包目前分類（ZIP）**：把整個分類的範本一次輸出成壓縮檔；選 PPTX 時則輸出成一份多頁簡報

## 其他

- Logo（可調大小、四角位置、白底框）、頁尾（公司｜日期｜頁碼）與 6 組商務配色
- 圖片裁切：全部圖片共用 3×3 預設焦點，單張圖片可按 ✂ 點選主體位置並放大 100–400%
- 全域字級 70–140%，所有範本的文字一起縮放
- 復原／重做（`Ctrl/Cmd+Z`、`Ctrl/Cmd+Y`），記錄文字、樣式、選圖順序與裁切
- 文字超出範本容量時會提醒，不會默默被裁掉
- **專案存檔／載入**：所有頁面的文字、逐字稿、配色與用到的圖片一起存成 `.pptgen.json`，換電腦或隔天再開都能接續
- 深／淺色外觀切換；中文自動避頭尾（標點不會落在行首）
- 微動態（取自 [Motion Library 動態收藏](https://kittenjam-motion-library.vercel.app/)）：分頁與尺寸切換的滑塊會滑到新位置、
  按鈕按下去有漣漪與下沉回饋、「下載」與「分享」執行時原地轉圈、完成打勾再復原、
  版型與照片縮圖依序浮現；系統開啟「減少動態效果」時全部停用
- 快捷鍵：`Ctrl/Cmd+S` 下載、`Ctrl/Cmd+Shift+C` 複製、`Alt+←/→` 切換範本
- 圖片只在你的瀏覽器中處理，不會上傳到任何伺服器
- 單一 HTML 檔，也可下載後離線使用

## 手機與 App（PWA）

- 響應式版面：手機／平板上畫布固定在上方，設定分成底部「頁面／內容／版型／照片／樣式」分頁，選單改成底部面板；按鈕觸控範圍至少 44px
- 可安裝成 App（Android／電腦 Chrome、Edge 會出現「安裝」；iPhone 用 Safari「分享 → 加入主畫面」），安裝後可離線使用
- Android 安裝後，可從相簿直接「分享」照片到本 App
- 手機上支援「分享」按鈕，把輸出的圖片或 PPTX 直接傳到 LINE、相簿等；畫布超過裝置上限時自動降倍率輸出

## 開發

**源碼在 `src/`，`index.html` 是產生出來的**：

```
src/shell.html    HTML 骨架（含 /*@CSS@*/ 與 /*@JS@*/ 兩個佔位符）
src/style.css     <style> 的內容
src/js/*.js       依檔名排序串成一支 <script>（同一支 script 內 const／let 才是同一個作用域）
```

```sh
node build.mjs            # 產生 index.html（或 npm run build）
node build.mjs --check    # 只檢查 index.html 是否與 src/ 同步（npm run check）
```

改完 `src/` 一定要 build，再把 `index.html` 一起 commit —— GitHub Pages 送的是 `index.html`。**不要直接改 `index.html`**（檔案開頭有標記提醒），下次 build 會蓋掉；`npm test` 也會抓「src/ 改了但忘記 build」。

產出的 `index.html` 仍然是**單一檔案、零依賴**（HTML + CSS + JS 全部內嵌），可以直接用瀏覽器開、可以下載離線用；`manifest.webmanifest`、`sw.js`、`icons/` 提供 PWA 安裝與離線快取。修改後如要讓已安裝的使用者立即更新，請調高 `sw.js` 裡的 `VERSION`。

### 自動測試（GitHub Actions）

`.github/workflows/test.yml` 在每次 push 到 `main` 與每個 PR 上跑：先 `node build.mjs --check`（幾秒，抓「改了 src/ 忘記 build」），再跑完整測試。跑在 `ubuntu-latest`，用 runner 內建的 Chrome；容器需要 `--no-sandbox`，所以 workflow 設了 `CHROME_FLAGS`（本機預設不加，沙箱照開）。失敗時會把失敗的測試名稱與訊息變成 **annotation**（`/check-runs/{id}/annotations` 公開可讀，不必登入抓 log）。

`.github/workflows/smoke.yml` 在 Pages 部署完成後（workflow 名稱是 `pages-build-deployment`）、每天一次、或手動觸發，用**真實網址**檢查本機與 CI 都看不到的事：

```sh
node test/smoke.mjs https://cormort.github.io/ppt-layout-generator/    # 也可以自己跑
```

- 線上的 `index.html` 與 repo 的檔案**逐字元相同**（CRLF 正規化；Pages 傳播可能幾十秒，會重試 90 秒）→ 抓「線上還是舊版」
- 線上 `sw.js` 的 `VERSION` 與 repo 一致 → 抓「舊 service worker 卡住」
- `manifest.webmanifest` 解析得開、每個 icon 都回 200 → 抓 PWA 安裝壞掉
- headless Chrome 開真的網址：版型數量與 repo 一致、沒有 console 錯誤

⚠ Pages 是「push 就部署」，Actions 是平行跑的——**測試紅了不會自動阻止部署**。這是刻意的取捨：這道門還年輕（第一次紅是因為 runner 比本機慢、匯出逾時），而單人專案的回復成本只有一分鐘的 revert。等 CI 連續一段時間穩定、或開始在手機／GitHub 網頁上直接改檔案，再考慮改成 `deploy.yml`（測試過 → artifact → deploy-pages）把門裝起來。

範本都放在 `def({id, cat, name, hint, render(c)})` 裡，`render` 回傳 1920×1080 的 SVG 字串：

- `c.imgs` 已選圖片、`c.t` 文字欄位、`c.col` 由主色衍生的配色、`c.tf`／`c.bf` 字體、`c.id()` 產生唯一 id
- 常用工具：`T()` 文字、`wrap()` 斷行、`mosaic()` 把形狀陣列裁成圖片、`stack()` 標題區塊、`items()` 項目清單、`strip()`／`band()`／`annular()` 幾何

### 去背：為什麼沒有接 ML 模型（2026-10 評估）

`src/js/66-cutout.js` 是純 canvas 演算法（四邊取樣背景色 → 連通洪水填充 → alpha 羽化），0 KB、瞬間完成，但只對白底／純色／攝影棚背景可靠；生活照、雜亂背景、頭髮、主體與背景同色時抓不準。評估過接 [`@imgly/background-removal`](https://github.com/imgly/background-removal-js)（IS-Net，瀏覽器內 WASM／WebGPU 推論），**決定先不接**，維持現狀。

| | 現在的演算法 | ML 模型 |
|---|---|---|
| 簡單背景（商品、白牆、棚拍） | 夠用 | 也行，大材小用 |
| 複雜背景、髮絲、同色主體 | 基本上不行 | 強項 |
| 成本 | 0 KB、瞬間 | 首次下載模型＋onnxruntime 約 40–80MB；手機一張數秒到十幾秒、吃記憶體 |
| 架構 | 單檔零依賴 | 破壞「單一 HTML、零依賴」 |

**資料外流**：照片本身不會外流——推論在瀏覽器裡跑、圖片不上傳。但套件**預設從 IMG.LY 的 CDN 抓模型與 WASM**，對方看得到使用的 IP、時間與 Referer（照片不會送出）。要做到「完全不連第三方」，得把模型檔自己放在 Pages 上、用 `publicPath` 指回自己的網址。

**授權**：`@imgly/background-removal` 是 **AGPL-3.0**（模型 IS-Net 本身是 Apache-2.0）。本 repo 公開、原始碼本來就公開，實務影響不大；但目前 repo 沒有 LICENSE，接進來等於整個專案要照 AGPL 釋出，日後要閉源或商用就得買 IMG.LY 商業授權。

**如果哪天要接**（例如使用者常拿生活照去背），照這幾條做：

- 保留現有演算法當「快速去背」，另加「精準去背（AI）」按鈕，**按了才下載**，先提示大小、建議用 Wi-Fi
- 模型檔**不要**放進 `sw.js` 的預先快取（否則每次調 `VERSION` 所有已安裝的人都重抓 40MB）；首次使用時存進獨立的 cache，改版時不清
- 自己架：Pages 單檔上限 100MB、整站 1GB 放得下，但模型進 git 會讓 repo 膨脹，可改放 Release 附檔或另開 repo
- 若不想被 AGPL 綁：自己用 onnxruntime-web 跑寬鬆授權的小模型（例如 U²-Net 小版，約 5MB），品質略差、要多寫一些膠水程式
