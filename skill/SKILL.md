# 用 Markdown 大綱產生簡報（pptgen）

排版、字級、斷行、逐字稿寫進備忘稿都已經由工具處理並驗證過。你的工作只有：**寫大綱 → 檢查 → 只修有問題的頁 → 產生 PPTX**。不要自己寫排版程式，也不要逐頁看預覽圖（很耗 token），除非使用者要求。

工具位置：`{{PPTGEN}}`（以下寫成 `pptgen`，實際執行用 `node "{{PPTGEN}}" …`）。需要 Node 22 以上與 Chrome 或 Edge。

## 流程

1. **寫大綱**存成 `.md`（格式見下）。每頁一個重點；逐字稿寫在 `>` 行，口語、完整句子。
2. **檢查**：`node "{{PPTGEN}}" check 大綱.md` —— 不產生檔案，只回報版型分配與「哪幾頁、哪個欄位放不下」。
3. **只修被點名的頁**：縮短文字、拆成兩頁，或換版型（見容量表）。改完再 check，直到顯示「✓ 所有頁面的文字都放得下」或剩下的提醒是使用者同意保留的。
4. **產生**：`node "{{PPTGEN}}" build 大綱.md -o 簡報.pptx [--palette 商務藍]`
5. 回報給使用者：頁數、幾頁有逐字稿、檔案路徑；若有封面／章節頁，提醒照片目前是示意圖（見「照片」）。

### 修改既有的 PPTX

1. `node "{{PPTGEN}}" from-pptx 舊簡報.pptx -o 大綱.md` —— 讀出每頁的標題、項目、表格與逐字稿（比直接讀 PPTX 省很多 token）。
2. 只改使用者要求的頁，其他頁原樣保留；接著照上面的 check → build。
3. 只想換版面、不改內容時，直接 `node "{{PPTGEN}}" build 舊簡報.pptx -o 新簡報.pptx`，原簡報的照片會一起帶過來。
4. 圖表、SmartArt 無法轉換（工具會回報數量），提醒使用者另外處理。

需要看某幾頁長相時才用：`node "{{PPTGEN}}" preview 大綱.md --pages 1,5 -d 預覽資料夾`，再讀 PNG。

## 大綱格式

```markdown
<!-- 版型: 封面 -->
# 簡報標題
## 副標題
主講人｜單位
> 封面逐字稿。

---
數字: 01
# 第一章　背景
## 一句話說明
> 章節頁逐字稿。

---
# 三個重點
## 這一頁的主旨
- 重點一|補充說明
- 重點二|補充說明
> 這一頁要講的內容。

---
# 驗收指標
| 指標 | 目標 | 說明 |
|---|---|---|
| 正確率 | 100% | 與人工結果逐筆核對 |
```

- 每頁用 `---` 分隔（或直接用下一個 `# 標題` 開新頁）。
- `#` 標題、`##` 副標題、`數字: 01` 章節大數字、`- 重點|說明` 或 `1. 重點|說明` 項目、`| 表格 |`（第一列是表頭）、`>` 逐字稿（空的 `>` 行＝分段）、其他文字＝內文。
- `<!-- 版型: … -->` 可省略；省略時依內容自動挑：有 `數字:` → 章節頁、有表格 → 表格、第一頁 → 封面、只有標題 → 大標題、有項目 → 條列、只有內文 → 段落。

## 版型與容量（文字頁不需要照片）

| 寫法 | id | 適合 | 容量 |
|---|---|---|---|
| 條列 | `tList` | 一般內容頁 | 最多 24 項；7 項以上自動分兩欄；每項「重點\|說明」，說明一兩句 |
| 方格 | `tGrid` | 並列的 2–12 個概念 | 每格標題短（≤12 字）、說明 ≤40 字 |
| 表格 | `tTable` | 比較、指標、對照 | ≤18 列、建議 ≤5 欄；單格文字短 |
| 段落 | `tText` | 說明性文字 | 2–5 段，內文後可接條列 |
| 引言 | `tQuote` | 金句、結語 | 標題放金句（≤60 字），副標題放出處 |
| 封面 | `split` | 第一頁 | 標題 ≤16 字、副標題、內文 1–3 行（含照片） |
| 章節 | `bignum` | 章節開頭 | `數字:` ＋短標題＋一句說明（含照片） |
| 大標題 | `ocean` | 只有大標題的過場頁 | 標題 ≤14 字（含照片） |

| 長條／橫條／折線／環圈 | `cBar` `cHbar` `cLine` `cPie` | 數據 | 項目寫成表格：第一欄類別、其餘欄數值（≤4 組），第一列可放系列名稱；內文＝資料來源。數字表格不指定版型時會自動變圖表 |
| 雜誌封面／專題／文章／目錄 | `mCover` `mFeature` `mColumns` `mIndex` | 年報、刊物感的頁面 | 襯線字；文章頁內文長可放 600 字以上（分兩欄） |
| 前後對比 | `cmp` / `cmpVs` | 改造前後、方案 A/B、過去現在 | 一定要 2 張照片；項目寫「之前\|說明」「之後\|說明」兩行。`cmp` 是滿版色帶（直式自動改上下堆疊），`cmpVs` 是兩張圓角照片＋中間 VS |
| 照片牆 | `wall` | 活動紀錄、作品集、旅遊 | 2–6 張照片自動拼牆；標題會疊在底部漸層，標題 ≤14 字 |
| 大字編號目錄 | `tocNum` | 章節目錄 | 項目每行一章（最多 4），數字自動 01、02… |

**社群圖卡**：加 `--ratio 1:1`、`4:5`、`3:4` 或 `9:16`，可用版型為文字頁 5 組、圖表 4 組、對比 2 組、照片牆 1 組、目錄大字編號 1 組與圖卡（`kPhoto` 照片公告、`kAnnounce` 活動公告：項目寫「時間｜…」、`kList` 重點清單、`kNumber` 數據亮點：用 `數字:`、`kQuote` 金句）；其他版型會自動換成相近的圖卡。3:4 是 FB／小紅書直式最常用的尺寸。

完整清單（含 47 組 16:9 版型）：`node "{{PPTGEN}}" templates`。

**放不下時的優先順序**：先縮短「說明」→ 再拆頁 → 欄位多的改 `| 表格 |` → 並列短項改 `tGrid`。標題超過兩行會被截斷，控制在 30 字內。

## 樣式選項

- `--palette` 商務配色：藏青金、商務藍、深灰橘、墨綠米、酒紅灰、科技紫；或 `--color #hex --accent #hex`
- `--font 標楷體`（標題）、`--body-font`（內文）、`--scale 90`（全域字級 %）
- `--text flow`：文字框改成整段（使用者之後要在 PowerPoint 大量改字時用，改字會自動重排）
- `--text image`：文字轉成圖片（換電腦字型不同也不跑版，但不能改字）
- `--quality small`：底圖 1 倍，檔案較小
- `--html 簡報.html`：同時輸出單一 HTML 簡報（瀏覽器開啟即播，P 鍵簡報者檢視含逐字稿與計時）。使用者要「用瀏覽器播」「傳給別人看」「沒有 PowerPoint」時加上
- `--project 簡報.pptgen.json`：另存網頁版專案檔，使用者可到 https://cormort.github.io/ppt-layout-generator/ 「載入專案」換照片、微調

## 照片

命令列版不放照片：封面、章節、大標題等照片版型會用示意風景圖。若使用者要放自己的照片，加 `--project` 產生專案檔，請使用者在網頁版載入後替換照片再輸出；或全部改用文字頁版型。

## 注意

- 逐字稿只會進備忘稿，不會出現在投影片上；投影片上的字要比逐字稿精簡。
- 修改既有簡報時，只改有變動的頁，保留其他頁原文。
- 工具在本機瀏覽器內執行，大綱與檔案不會上傳。
