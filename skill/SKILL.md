# 用 Markdown 大綱產生簡報（pptgen）

排版、字級、斷行、逐字稿寫進備忘稿都已經由工具處理並驗證過。你的工作只有：**寫大綱 → 檢查 → 只修有問題的頁 → 產生 PPTX**。不要自己寫排版程式，也不要逐頁看預覽圖（很耗 token），除非使用者要求。

工具位置：`{{PPTGEN}}`（以下寫成 `pptgen`，實際執行用 `node "{{PPTGEN}}" …`）。需要 Node 22 以上與 Chrome 或 Edge。

## 流程

1. **寫大綱**存成 `.md`（格式見下）。每頁一個重點；逐字稿寫在 `>` 行，口語、完整句子。
2. **檢查**：`node "{{PPTGEN}}" doctor 大綱.md`（容量＋健檢＋可自動修的清單；需要時加 `--fix` 直接修好並另存）——不想自動修也可以用 `check`。 —— 不產生檔案，只回報版型分配與「哪幾頁、哪個欄位放不下」。
3. **只修被點名的頁**：縮短文字、拆成兩頁，或換版型（見容量表）。改完再 check，直到顯示「✓ 所有頁面的文字都放得下」或剩下的提醒是使用者同意保留的。
4. **產生**：`node "{{PPTGEN}}" build 大綱.md -o 簡報.pptx [--palette 商務藍]`；加 `--doctor` 會在輸出前先健檢（加 `--fix` 先自動修再輸出）
5. 回報給使用者：頁數、幾頁有逐字稿、檔案路徑；若有封面／章節頁，提醒照片目前是示意圖（見「照片」）。

### 修改既有的 PPTX

1. `node "{{PPTGEN}}" from-pptx 舊簡報.pptx -o 大綱.md` —— 讀出每頁的標題、項目、表格與逐字稿（比直接讀 PPTX 省很多 token）。
2. 只改使用者要求的頁，其他頁原樣保留；接著照上面的 check → build。
3. 只想換版面、不改內容時，直接 `node "{{PPTGEN}}" build 舊簡報.pptx -o 新簡報.pptx`，原簡報的照片會一起帶過來。
4. 圖表、SmartArt 無法轉換（工具會回報數量），提醒使用者另外處理。

需要看某幾頁長相時才用：`node "{{PPTGEN}}" preview 大綱.md --pages 1,5 -d 預覽資料夾`，再讀 PNG。

## 大綱格式

```markdown
<!-- 版型: 封面 -->
# 簡報標題
## 副標題
主講人｜單位
> 封面逐字稿。

---
數字: 01
# 第一章　背景
## 一句話說明
> 章節頁逐字稿。

---
# 三個重點
## 這一頁的主旨
- 重點一|補充說明
- 重點二|補充說明
> 這一頁要講的內容。

---
# 驗收指標
| 指標 | 目標 | 說明 |
|---|---|---|
| 正確率 | 100% | 與人工結果逐筆核對 |
```

- 每頁用 `---` 分隔（或直接用下一個 `# 標題` 開新頁）。
- `#` 標題、`##` 副標題、`數字: 01` 章節大數字、`- 重點|說明` 或 `1. 重點|說明` 項目、`| 表格 |`（第一列是表頭）、`>` 逐字稿（空的 `>` 行＝分段）、其他文字＝內文。
- `<!-- 版型: … -->` 可省略；省略時依內容自動挑：有 `數字:` → 章節頁、有表格 → 表格、第一頁 → 封面、只有標題 → 大標題、有項目 → 條列、只有內文 → 段落。也可以寫中文名稱（對比、照片牆、數據並列、人物引言、地圖、撕紙、宣紙、去背、雙色調、感謝…）。

## 版型與容量（文字頁不需要照片）

| 寫法 | id | 適合 | 容量 |
|---|---|---|---|
| 條列 | `tList` | 一般內容頁 | 最多 24 項；7 項以上自動分兩欄；每項「重點\|說明」，說明一兩句 |
| 方格 | `tGrid` | 並列的 2–12 個概念 | 每格標題短（≤12 字）、說明 ≤40 字 |
| 表格 | `tTable` | 比較、指標、對照 | ≤18 列、建議 ≤5 欄；單格文字短 |
| 段落 | `tText` | 說明性文字 | 2–5 段，內文後可接條列 |
| 引言 | `tQuote` | 金句、結語 | 標題放金句（≤60 字），副標題放出處 |
| 封面 | `split` | 第一頁 | 標題 ≤16 字、副標題、內文 1–3 行（含照片） |
| 章節 | `bignum` | 章節開頭 | `數字:` ＋短標題＋一句說明（含照片） |
| 章節（無照片） | `secPlain` | 沒有照片也要章節頁 | `數字:` ＋短標題＋一句說明；色塊放數字、另一側放章名，任何尺寸 |
| 大標題 | `ocean` | 只有大標題的過場頁 | 標題 ≤14 字（含照片） |

| 長條／橫條／折線／環圈 | `cBar` `cHbar` `cLine` `cPie` | 數據 | 項目寫成表格：第一欄類別、其餘欄數值（≤4 組），第一列可放系列名稱；內文＝資料來源。數字表格不指定版型時會自動變圖表 |
| 雜誌封面／專題／文章／目錄 | `mCover` `mFeature` `mColumns` `mIndex` | 年報、刊物感的頁面 | 襯線字；文章頁內文長可放 600 字以上（分兩欄） |
| 前後對比 | `cmp` / `cmpVs` | 改造前後、方案 A/B、過去現在 | 一定要 2 張照片；項目寫「之前\|說明」「之後\|說明」兩行（只取前 2 項）。`cmp` 是滿版色帶（直式自動改上下堆疊），`cmpVs` 是兩張圓角照片＋中間 VS |
| 照片牆 | `wall` | 活動紀錄、作品集、旅遊 | 2–6 張照片自動拼牆；標題會疊在底部漸層，標題 ≤14 字 |
| 大字編號目錄 | `tocNum` | 章節目錄 | 項目每行一章（最多 4），數字自動 01、02… |
| 地圖 | `twMap` | 各縣市的重點（農業、人口、損失…） | 只有 16:9。項目寫「縣市\|說明\|說明」：第一欄是縣市名（臺／台都可、可省市縣），其餘每欄一行說明；≤12 個縣市（多的會被略過），澎湖／金門／連江畫成下方小圖。標題在右上、副標當大字，內文＝資料來源 |
| 數據並列 | `tStats` | 成果摘要、KPI 回顧 | 項目寫「數字\|標籤\|說明」，2–4 個，不用照片 |
| 人物引言 | `kPortrait` | 人物專訪、推薦語 | 1 張人像；標題放金句（≤40 字），副標題放出處 |
| 中國風 | `cnTear` / `cnQuote` | 文化、茶、工藝、年節 | `cnTear` 需要 1 張照片（宣紙＋撕紙邊＋直排標題＋印章）；`cnQuote` 不用照片，標題放金句（直排，≤20 字）。底色建議選米白 |
| 感謝頁 | `thanks` | 最後一頁 | 標題放感謝詞（如「謝謝聆聽」），副標題一句話 |
| 去背主體 | `cutoutCard` | 商品、人像、logo 放色塊上 | 1 張照片；去背過的會完整放進色塊，沒去背的自動裁成圓形 |
| 雙色調封面 | `duotone` | 年報封面、主題頁 | 1 張照片，模板自動用主色增值壓暗；標題 ≤12 字最有力 |
| 斜切時間軸 | `diagTime` | 公司沿革、專案里程碑、三年計畫 | 只有 16:9，**要 1 張照片**（滿版斜切）。項目寫「年份\|事件名\|說明」，最多 5 個節點（多的會被略過）；年份 ≤8 字、事件名 ≤12 字（英文更短）、說明 ≤45 字。左到右＝時間順序，節點沿斜線往上，適合「成長」的故事 |
| 下緣色帶 | `cBand` | 發表會、開幕、課程封面（任何尺寸） | 照片在上、下方主色帶放標題；標題一行放得下最好（≤14 字），副標是色帶裡的小字，內文放色帶右側（窄版面接在標題下）。不用照片也可以 |
| 中央字標 | `cLockup` | 電影／書籍／活動海報（任何尺寸） | 滿版照片＋置中字標：副標＝上方小標（建議英文或短句、≤20 字）、標題＝大字（≤10 字最有力、自動縮到 3 行內）、內文＝下面一句話。自動壓中央暗霧，淺色照片也讀得到 |
| 夜空羽化 | `nightWall` | 活動回顧、影展、品牌牆、週年（只有 16:9） | **第一張＝中央主圖**，其餘放進四周 7×4 的截圖牆；標題是上方字標（≤10 字、大寫最好）、內文是下方字幕（最多 3 行、一行 ≤22 字），副標是字幕上一行小字。深色底＋四周羽化，適合「很多張圖但要有主角」的場合 |
| 曲面拼貼 | `posterWall` | 活動回顧、影展／作品集、品牌牆（只有 16:9） | 先選** 1 張主圖**（放左側圓弧面板，標題壓在上面）＋多張截圖（右側 35 格透視網格＋倒影）。照片少（3–6 張）時會重複取不同裁切，仍看起來像一面牆；超過 12 張只取前 12 張。標題 ≤10 字最有力（大寫字距會放大），副標一行小字，內文 1–2 行 |
| 花瓣扇 | `petalFan` | 標題頁、主題頁、作品集（16:9 與社群圖卡都能用） | 5–8 張照片排成一朵花（一片花瓣一張；只給 1 張時每片花瓣各裁一部分，效果也不錯）；**副標題是花上方那行小字**（建議一個英文詞，例如 `MASTERPIECE`），標題是主標（≤10 字最有力），內文 1–2 行。16:9 花朵在左、文字在右；直式花朵在上、文字在下 |

**整套簡報**：`--suite 年度報告`（或 課程講義、品牌提案、專案回顧）會把整份簡報一次換成同一套設計：配色＋字體＋每頁依角色對應的版型。它會**蓋掉大綱裡指定的版型**，所以想保留自己挑的版型就不要加這個參數。

網頁版的「檢視 → 簡報健檢」會一次列出文字放不下、缺照片、沒有標題、標題重複的頁面，點一列就跳到那一頁（命令列的 `check` 只報容量，兩者互補）。

**社群圖卡**：加 `--ratio 1:1`、`4:5`、`3:4` 或 `9:16`，可用版型為文字頁 6 組、圖表 4 組、對比 2 組、照片牆 1 組、目錄大字編號 1 組、圖卡 8 組（`kPhoto` 照片公告、`kAnnounce` 活動公告：項目寫「時間｜…」、`kList` 重點清單、`kNumber` 數據亮點：用 `數字:`、`kQuote` 金句、`kPortrait` 人物引言、`petalFan` 花瓣扇）、中國風 2 組、感謝頁 1 組；其他版型會自動換成相近的圖卡。3:4 是 FB／小紅書直式最常用的尺寸。

完整清單（含 66 組 16:9 版型）：`node "{{PPTGEN}}" templates`。

**放不下時的優先順序**：先縮短「說明」→ 再拆頁 → 欄位多的改 `| 表格 |` → 並列短項改 `tGrid`。標題超過兩行會被截斷，控制在 30 字內。

## 樣式選項

- `--palette` 商務配色：藏青金、商務藍、深灰橘、墨綠米、酒紅灰、科技紫；或 `--color #hex --accent #hex`
- `--font 標楷體`（標題）、`--body-font`（內文）、`--scale 90`（全域字級 %）
- `--text flow`：文字框改成整段（使用者之後要在 PowerPoint 大量改字時用，改字會自動重排）
- `--text image`：文字轉成圖片（換電腦字型不同也不跑版，但不能改字）
- `--quality small`：底圖 1 倍，檔案較小
- `--html 簡報.html`：同時輸出單一 HTML 簡報（瀏覽器開啟即播，P 鍵簡報者檢視含逐字稿與計時）。使用者要「用瀏覽器播」「傳給別人看」「沒有 PowerPoint」時加上
- `--project 簡報.pptgen.json`：另存網頁版專案檔，使用者可到 https://cormort.github.io/ppt-layout-generator/ 「載入專案」換照片、微調

## 照片

命令列版不放照片：封面、章節、大標題等照片版型會用示意風景圖。若使用者要放自己的照片，加 `--project` 產生專案檔，請使用者在網頁版載入後替換照片再輸出；或全部改用文字頁版型。

## 注意

- 逐字稿只會進備忘稿，不會出現在投影片上；投影片上的字要比逐字稿精簡。
- 修改既有簡報時，只改有變動的頁，保留其他頁原文。
- 工具在本機瀏覽器內執行，大綱與檔案不會上傳。
